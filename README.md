## 后台真锁（/admin）
- 根目录 `_worker.js`：/admin 先在服务器端验签，通过才放行静态后台页；密码绝不写进仓库和前端。
- 在 Cloudflare Pages 项目 → 设置 → 环境变量 里添加 `HYJJ_ADMIN_KEY`，值就是你的后台密码，重新部署后生效。
- 登录成功后发 24 小时 HMAC 签名 Cookie（HttpOnly），退出点后台顶部的“退出登录”。
- 未配置 `HYJJ_ADMIN_KEY` 时 /admin 只显示配置指引，不放行。
