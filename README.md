## 赛制
L-001 入门测试不计分，只有一次机会，说出昔涟即算通过；预备役选手须先通过本题才能进入正式比赛。
青铜到白银 1 分，钻石到荣耀 2 分，王者 3 分；荣耀题答对一半算 1 分。荣耀、王者题各有两次机会，取两次中最好的一次计分。
绝望炼狱有三次机会：第 1 轮提示词「这是谁？」，答对 5 分（含一次答对额外 2 分）；第 2 轮答对 2 分；第 3 轮答对 1 分。H-003 答对一半按 2 分算：认出可露希尔且认出卫戍协议终端主题为全对，只认出可露希尔为对一半。
无间地狱只有一次机会，提示词「这是谁？出自于哪里？」，人物和出处都答对得 5 分，否则 0 分，不设对一半。AI 拒绝作答记为「拒答」，计 0 分。淘汰线以下选手不可挑战无间地狱。本轮 VH-001 即属此级。
花果山关卡（青铜/白银/钻石）只要有一个 AI 一轮通过，即进入荣耀、王者难度。
